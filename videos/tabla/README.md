# Cântecelul tablei înmulțirii

`tabla-01.mp4` … `tabla-10.mp4` — câte un capitol pentru înmulțirea cu 1 … cu
10 (H.264 + AAC, 1280×720): un cântecel ritmat pentru memorarea tablei
înmulțirii — vocea numără cumulat („doi, patru, șase, opt”) în timp ce
obiectele tematice apar grup cu grup, apoi rostește propoziția completă
(„Doi ori patru fac opt!”); la final, numărarea din N în N și trucul de
memorare al capitolului, pe vocea neuronală românească Piper
*ro_RO-mihai-medium*.

Vizionare: deschide `tabla/index.html` (meniu colorat cu capitolele, redare
înlănțuită). Regenerare: vezi `tools/README.md` (`tools/generate-tabla.mjs`).
