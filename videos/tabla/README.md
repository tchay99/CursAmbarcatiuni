# Cântecelul tablei înmulțirii

`tabla-01.mp4` … `tabla-10.mp4` — câte un capitol pentru înmulțirea cu 1 … cu
10 (H.264 + AAC, 1280×720): vocea narează pe rând fiecare operație și
rezultatul ei („Doi ori patru fac opt!”), iar pe ecran lista înmulțirilor
capitolului se completează rând cu rând (cele deja narate rămân la vedere);
alături, o rețea de obiecte tematice crește cu un rând per operație. Voce
neuronală românească Piper *ro_RO-mihai-medium*.

Vizionare: deschide `tabla/index.html` (meniu colorat cu capitolele, redare
înlănțuită). Regenerare: vezi `tools/README.md` (`tools/generate-tabla.mjs`).
