# Cântecelul tablei înmulțirii

`tabla-01.mp4` … `tabla-10.mp4` — câte un capitol pentru înmulțirea cu 1 … cu
10 (H.264 + AAC, 1280×720): un cântecel în rime pentru memorarea tablei
înmulțirii, cu obiecte tematice care apar grup cu grup, totaluri cumulate
(adunarea repetată devine înmulțire), numărarea din N în N și trucuri de
memorare, pe vocea neuronală românească Piper *ro_RO-mihai-medium*.

Vizionare: deschide `tabla/index.html` (meniu colorat cu capitolele, redare
înlănțuită). Regenerare: vezi `tools/README.md` (`tools/generate-tabla.mjs`).
