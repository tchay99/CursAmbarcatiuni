# Tabla înmulțirii — videoclipuri pe capitole

`tabla-01.mp4` … `tabla-10.mp4` — câte un capitol pentru înmulțirea cu 1 … cu
10 (H.264 + AAC, 1280×720), în stil pentru pre-adolescenți (temă întunecată,
accente neon): vocea narează pe rând fiecare operație („Doi ori patru fac
opt!”), lista înmulțirilor se completează rând cu rând pe ecran, iar la final
rămâne afișată integral, de repetat cu voce tare. Voce neuronală românească
Piper *ro_RO-mihai-medium*, beat lo-fi discret pe fundal.

Vizionare: deschide `tabla/index.html` (meniu cu capitolele, redare
înlănțuită). Regenerare: vezi `tools/README.md` (`tools/generate-tabla.mjs`).
